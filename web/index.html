Make yourself at home

  

    
Ctrl+Enter
Compile the current source file, refresh and sync

    
Ctrl+Shift+F
Search across the project; switch to citations, labels or commands

    
F12 / Alt+click
Follow an input, reference, citation or custom command

    
Alt+Shift+D
Duplicate the current or selected source lines

    
Alt+Up / Down
Move current or selected lines

    
Ctrl+click
Add a source cursor; Escape returns to one cursor

    
Ctrl+D
Select the word, then add its next occurrence

    
Ctrl+Alt+Left / Right (or Alt+PageUp / PageDown)
Switch editor view tabs in either direction

    
Ctrl+Alt+N
Open another view of the current source file

    
Ctrl+S
Save all opened drafts

    
Sync arrows
Source cursor → PDF; visible PDF page center → source

    
Double-click
Select a source word; on the PDF, sync to source

    
Ctrl+wheel / trackpad pinch
Zoom only the PDF when pointing over it

    
Ctrl+F
Search the source or PDF pane you last used, or the focused raw log; Enter / Shift+Enter cycles matches

    
Ctrl+/
Comment or uncomment selected source lines

    
Ctrl+Shift+Enter
Compile the sidebar build target

    
Ctrl+Space
Show completions; arrows select, Enter / Tab accepts, Escape dismisses

    
Enter
Continue indentation; environment completions insert the matching end

    
Tab / Shift+Tab
Indent / unindent source lines

    
Drag divider
Resize panes; double-click resets to 50/50
